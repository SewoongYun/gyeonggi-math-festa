시트 없이 쓰기

구글 시트를 연결하지 않았다면, 여기서 편집한 내용을 data/apps.json으로 내려받아 GitHub 저장소의 같은 파일에 덮어쓰면 됩니다.

연결 방법

읽기(사이트 표시): 구글 시트를 공유 → 링크가 있는 모든 사용자, 뷰어로 바꾸면 끝입니다. 시트에서 셀을 고치면 사이트에 바로 반영됩니다.

쓰기(이 관리자 화면에서 저장)까지 하려면 아래 Apps Script를 연결합니다.

  1. 시트(헤더: ID, 구분, 제목, 한줄소개, 체험링크, 목적, 수학적 내용, 프로그램 설명, 만드는 방법, 제작자, 태그, 공개, 순서)에서 [확장 프로그램 → Apps Script]를 연다.
  2. 저장소의 apps-script/Code.gs 내용을 붙여 넣고 저장한다.
  3. 프로젝트 설정 → 스크립트 속성에 ADMIN_KEY(원하는 비밀번호)를 추가한다.
  4. 함수 setup을 한 번 실행한다(권한 허용).
  5. [배포 → 새 배포 → 웹 앱], 실행 '나', 액세스 '모든 사용자'로 배포하고 URL을 복사한다.
  6. 저장소의 config.js에서 apiUrl에 그 URL을, sheetEditUrl에 시트 주소를 넣고 커밋한다.
